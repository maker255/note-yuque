# 配置方式

`createOpenEditor/createOpenViewer`第二个参数支持一个对象

```typescript
const { createOpenEditor } = window.Doc;

const editor = createOpenEditor(document.body, {
  // 通用配置
  disabledPlugins:[],
  // 插件配置，参考各插件文档，key为插件名
  image:{...},
  clipboard:{...},
})
```

## 禁用插件

<code><font style="color:#BA9BF2;">disabledPlugins: Array<string></font></code>

支持传入一个插件列表，列表项为插件的名称字符串。

## 标题组件

<code><font style="color:#BA9BF2;">header: React.Component | React.FunctionComponent</font></code>

在文档上方渲染一个组件

## 编辑器类型

<code><font style="color:#BA9BF2;">uiSwitch: { default: 'simple' | 'default' | 'small' }</font></code>

小窗口编辑器传入 simple 即可或者 small

## 当前页面链接

<code><font style="color:#BA9BF2;">currentURL: string</font></code>

输出 html 的时候一些卡片会用到

## 适配器（envAdapter）

<code><font style="color:#BA9BF2;">envAdapter: null | EnvAdapter</font></code>

适配器是为了满足某些交互的响应在不同的设备环境下、或者不同业务场景下需要有不同的表现的需求。编辑模式和阅读模式都有自己的适配器。

## 虚拟渲染 (1.6.0 之后支持)

<code><font style="color:#BA9BF2;">virtualRendering: boolean</font></code>

## 暗黑模式（1.12.0 之后支持）

<code><font style="color:#BA9BF2;">darkMode: boolean</font></code>

## scrollNode

<code><font style="color:#BA9BF2;">scrollNode: HTMLElement| () => HTMLElement</font></code>

配置滚动容器，某些默认行为需要指定正确的滚动容器才能生效。未配置 scrollNode 建议直接让编辑器固定高度。

阅读器大纲需求配置真实的滚动容器。

## boundaryTopOffset `阅读器配置`

`number`

目前会影响大纲的滚动偏移量。
