✦ 我已经为您创建了 demo/Demo2.vue 并更新了 demo/App.vue。

  项目结构说明：
   * src/: 存放富文本编辑器的核心代码（库代码）。
   * demo/: 存放演示代码。App.vue 现在作为导航入口，可以在默认演示和新创建的 Demo2 之间切换。

  如何启动并使用 Demo2：
   1. 启动项目：
   1     npm run dev
   2. 进入 Demo2：在浏览器打开页面后，点击顶部的 “进入本地 MD 编辑模式 (Demo2)” 按钮。
   3. 编辑本地 .md 文件：
       * 点击 “打开本地 .md 文件”：这会调用浏览器的 File System Access API，允许您选择电脑上的 .md 文件。
       * 自动转换：程序会动态加载 marked 库将 Markdown 转换为编辑器识别的 HTML。
       * 实时预览：在下方可以看到从富文本实时转换回来的 Markdown 源码（使用了 turndown 库）。
       * 保存文件：点击 “保存文件” 即可将修改后的内容直接写回原始的 .md 文件。

  技术实现细节：
   * 本地文件操作：使用了现代浏览器的 window.showOpenFilePicker API，实现真正的本地文件读写。
   * 格式转换：由于 YuqueRichText 核心基于语雀的 Lake 引擎（主要处理 HTML/Lake 格式），我通过动态导入 https://esm.sh/marked
     (MD->HTML) 和 https://esm.sh/turndown (HTML->MD) 实现了与 Markdown 的互转。
   * 无需安装依赖：为了方便您直接运行，转换库采用了 CDN 动态引入，您无需执行 npm install 安装额外的 Markdown 处理库。
